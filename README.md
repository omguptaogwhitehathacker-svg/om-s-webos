# WebOS Desktop Environment

A sleek, browser-based desktop environment inspired by macOS, featuring a complete suite of productivity and entertainment tools.

## Features

- **Draggable Windows** - Move windows freely across the desktop with an intuitive drag-and-drop interface
- **Text Editor** - Built-in text editor for creating and editing files
- **File System** - Basic file management system for organizing your files
- **Music Player** - MP3 uploading and playback system
- **Mac-style Interface** - Clean, elegant design inspired by macOS
- **Responsive Design** - Works seamlessly in your browser

## Getting Started

1. Open `index.html` in your web browser
2. Start exploring the desktop environment
3. Create files, edit text, and upload your music files
